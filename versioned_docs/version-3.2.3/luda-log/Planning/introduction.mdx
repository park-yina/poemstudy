# Luda Log 전체 사이트 기획

## 프로젝트 개요

Luda Log는 단순히 프로젝트 결과물을 나열하는 포트폴리오 사이트가 아니다.

실제 개발 과정에서 발생했던 운영 경험과 구조 설계,
그리고 구현 과정 속 고민들을 하나의 archive 형태로 기록하기 위해 시작된 개발 아카이브 프로젝트이다.

기존의 포트폴리오 사이트들은 대부분 결과 중심으로 구성되어 있었다.

- 어떤 기술을 사용했는가
- 어떤 기능을 구현했는가
- 어떤 프로젝트를 진행했는가

하지만 실제 개발에서는
운영 중 발생하는 문제와 구조적인 고민,
그리고 왜 특정한 방향을 선택했는가가 훨씬 중요하다고 생각했다.

Luda Log는 이러한 과정 자체를 기록으로 남기기 위해 만들어졌다.

---

## 핵심 방향성

Luda Log는 다음과 같은 방향을 중심으로 설계되었다.

### 기록 중심 구조

프로젝트를 단순 게시글처럼 나열하는 대신,
하나의 운영 기록과 manuscript처럼 읽히도록 구성한다.

단순 기능 소개보다:

- 왜 이런 구조를 선택했는가
- 어떤 문제를 해결하려 했는가
- 어떤 운영 경험이 있었는가

를 중심으로 기록한다.

---

### Archive Experience

사이트 전체는 일반 블로그보다
하나의 archive room 혹은 manuscript archive처럼 보이는 것을 목표로 한다.

이를 위해:

- dark archive aesthetic
- runtime UI
- manuscript viewer
- workspace explorer
- tarot reconstruction

등의 구조를 도입하였다.

단순한 정보 탐색보다
기록을 열람하고 해석하는 경험에 가까운 방향을 지향한다.

---

### Runtime 기반 UI

Luda Log의 일부 영역은
단순 document viewer가 아니라
실행중인 runtime process처럼 동작하도록 설계하였다.

특히:

- PROJECT LOG
- DEV LOG
- Workspace Runtime

등은 일반 markdown viewer 대신
runtime terminal과 process window를 참고하여 구성하였다.

이를 통해 단순히 문서를 읽는 것이 아니라,
실행중인 시스템 내부를 탐색하는 느낌을 만들고자 했다.

---

## 기술 스택 선정 이유

### Docusaurus

Luda Log는 Docusaurus 기반으로 구축되었다.

선정 이유는 다음과 같다.

- markdown 기반 문서 관리
- versioning 지원
- category 기반 archive 구조
- 정적 배포 환경
- 유지보수 편의성

특히 versioning 기능은
단순 문서 버전 관리가 아니라
운영 기록의 스냅샷을 보존하는 방향으로 활용하고 있다.

---

### React 기반 구조

Docusaurus는 React 기반으로 동작하기 때문에:

- runtime UI
- workspace interaction
- animated overlay
- custom archive component

등을 자유롭게 확장할 수 있었다.

기본 문서 시스템 위에
하나의 archive runtime을 구축하는 방향으로 활용하고 있다.

---

## 주요 구성 요소

### Archive Room

프로젝트와 기록들을 archive 형태로 탐색하는 공간.

단순 리스트 구조 대신
분위기와 탐색 경험 자체를 중요하게 설계하였다.

---

### Workspace Runtime

IDE와 runtime window를 참고하여 만든 workspace 구조.

문서를 단순 markdown viewer로 보여주는 대신,
실행중인 workspace처럼 탐색 가능하도록 설계하였다.

---

### Manuscript Viewer

문서를 dashboard나 admin panel처럼 보여주지 않고,
실제 manuscript 혹은 기록 문서처럼 읽히도록 구성하였다.

typography와 whitespace를 중요하게 다루고 있다.

---

### Runtime Log System

PROJECT LOG와 DEV LOG는
실행중인 terminal process처럼 보이도록 구성하였다.

단순 code block이 아니라:

- boot sequence
- runtime session
- operational log

등의 분위기를 표현하는 방향으로 설계하였다.

---

## 지향하는 포트폴리오 방향

Luda Log는 결과만을 보여주는 사이트보다,
운영과 구조를 함께 기록하는 archive를 목표로 한다.

특히:

- 운영 중 발생한 문제
- 구조적인 의사결정
- runtime 설계
- UX 방향성
- 실제 사용 환경에서의 고민

등을 지속적으로 기록하고 정리하는 방향을 지향한다.

이 archive는 단순 포트폴리오를 넘어,
개발 과정 자체를 남기는 기록 시스템을 목표로 한다.
