<div markdown="1">

DevWIKI는 깃허브 포트폴리오로는 보여주기 어려운, 프로젝트별 문서 정리의 역할을 담당한다.

동시에 깃허브 블로그와의 차별성을 위해:

`사용자가 정말 이 기록을 클릭하게 만들 수 있는가`

라는 고민에서 출발한 구조이기도 하다.

특히 운영 과정에서 발생했던:

- 구조 변경
- 판단 과정
- 포기한 기능
- 예상하지 못했던 문제

등을 단순 기능 소개가 아니라,
테마를 가진 백과사전을 탐색하듯 읽게 만드는 것을 목표로 하였다.
