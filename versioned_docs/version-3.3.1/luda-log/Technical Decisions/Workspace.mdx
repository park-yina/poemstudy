<div markdown="1">
탐색기 구조를 채택한 가장 큰 이유는,
사용자가 이미 익숙하게 학습한 인터페이스를 활용하기 위함이었다.

일반 archive 및 wiki 구조에서는
문서 depth가 깊어질수록 탐색 자체에 대한 피로도가 증가하기 쉽다.

반면 파일 탐색기 형태의 구조는:

- folder 이동
- file 선택
- preview 열람

등의 흐름이 이미 익숙한 패턴으로 받아들여지기 때문에,
상대적으로 depth에 대한 거부감이 낮다고 판단하였다.

또한 Workspace는
홈의 CMD runtime과 하나의 흐름처럼 이어지도록 설계되었기 때문에,
단순 문서 리스트보다
`실제 작업 공간을 탐색하는 감각`에 가까운 방향을 목표로 하였다.
</div>

</details>
