# Realtime Ranking

JumpingBattle의 실시간 랭킹 흐름을 독립 runtime archive로 정리합니다.

이 섹션은 점수 이벤트가 발생하고, 순위가 갱신되며, 사용자에게 결과가 전달되는 과정을 하나의 운영 맥락으로 다룹니다.

## Archive Scope

- 실시간 점수 이벤트 흐름
- 랭킹 계산과 갱신 기준
- 동시성, 정합성, 지연 문제
- 운영 중 모니터링과 장애 대응

## Reading Flow

랭킹 런타임의 구조적 판단은 `Technical Decisions`에서, 실제 운영 중 마주한 문제는 `TroubleShooting`에서 이어서 정리합니다.
