# Archive Wiki

배포했던 프로젝트와 서비스들을
아카이브 형태로 정리하는 공간입니다.

기존 DEV WIKI가
구현 과정과 유지보수 기록 중심의 작업 공간이라면,

아카이브 위키는
완성된 프로젝트와 운영 결과물을 한눈에 정리하기 위한 공간에 가깝습니다.

실제 운영에 사용되었던 서비스 구조와
주요 기능, 사용 기술, 운영 과정에서의 기록들을 함께 보관합니다.

이 디렉토리의 문서를 기반으로:

- 아카이브 페이지
- 검색 레코드
- 인덱스 카드

등이 생성됩니다.
