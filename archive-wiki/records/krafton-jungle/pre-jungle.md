# 예비 정글러

보다 상세한 학습 기록과 당시의 정리 내용은
GitHub Blog의 정글 카테고리에 별도로 정리되어 있습니다.

해당 프로젝트는
크래프톤 정글 입과 이전,
수도권 인근의 예비 정글러들과 함께 진행한 프로젝트입니다.

당시에는 익숙한 기술보다,
새로운 구조와 협업 방식을 직접 경험하는 것을 우선으로 두고 기술 스택을 선정했습니다.

프론트엔드는 React 기반으로 구성하였고,
백엔드는 Spring Boot를 사용하여 역할을 분리했습니다.

또한 테스트와 QA,
프론트엔드와 백엔드 등의 영역을 나누어 진행하면서
초기 협업 구조와 역할 기반 개발 흐름을 경험하는 형태로 프로젝트를 운영했습니다.
# 담당 역할

- React 기반 프론트엔드 UI 구성
- 컴포넌트 구조 분리 및 화면 설계
- 기본 페이지 라우팅 및 상태 관리
- 협업 과정에서의 프론트엔드 구조 정리

또한 단순 기능 구현보다,
사용자 경험 자체를 하나의 UI 흐름으로 구성하는 방향을 고민했습니다.

그 과정에서:
- 앨범 형태의 UI 구조
- 사용자 경험 중심의 화면 전환
- Storybook 기반의 UI 버전 관리

등을 시도했습니다.

Storybook 기반 구조는
프로젝트 진행 과정에서 최종적으로 유지되지는 않았지만,
컴포넌트 단위 관리와 UI 기록 방식에 대한 초기 실험으로 남아 있습니다.
