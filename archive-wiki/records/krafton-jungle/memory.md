# 메모리 구조에 대한 학습


보다 상세한 학습 기록과 당시의 정리 내용은
GitHub Blog의 정글 카테고리에 별도로 정리되어 있습니다.

크래프톤 정글의 초반 과정에서는
CPU, RAM, Cache와 같은 하드웨어 구조와 메모리 계층에 대한 학습 비중이 높았습니다.

특히 단순 암기보다,
왜 특정 구조가 등장하게 되었는가를 이해하는 방식으로 접근했습니다.

철학사 수업에서
이전 시대의 철학을 비판적으로 계승하며 새로운 사상이 등장하듯,

컴퓨터 구조 또한:
- 하드디스크의 태생적인 속도 한계
- CPU 처리 속도의 지속적인 증가
- 그 과정에서 발생하는 병목 현상

등의 문제를 해결하는 방향으로 발전해왔다는 점이 인상적으로 남았습니다.

또한 이러한 흐름을 따라가다 보면,
모든 메모리는 계층 구조를 기반으로 동작한다는 점이 인상적으로 남았습니다.
또한,
CPU에 가까운 메모리일수록:
- 더 빠르고
- 더 비싸며
- 더 작은 크기를 가진다는 특징이 있었습니다.

세부적인 컨트롤러 구조와 동작 방식 또한 함께 학습했지만,
그보다 더 중요하게 느껴졌던 부분은
각 메모리가 서로 다른 역할을 분담하며 병목을 줄이기 위해 존재한다는 점이었습니다.

이후에는 이러한 계층 구조와 역할 분리가
추상화와 시스템 설계 전반에도 연결될 수 있다는 점에 흥미를 가지게 되었습니다.
