# 가상메모리

보다 상세한 학습 기록과 당시의 정리 내용은
GitHub Blog의 정글 카테고리에 별도로 정리되어 있습니다.


해당 주차에서는 가상 메모리의 개념 등을 학습했지만,
나에게 가장 인상적으로 남았던 부분은:

> 컴퓨터 시스템 전체는 결국 추상화 계층 위에서 동작한다

는 점이었습니다.

당시에는 왜 많은 개발 서적들이
컴퓨터를 “전구를 켜고 끄는 행위”로 설명하는지 잘 이해하지 못했습니다.

하지만 학습이 진행될수록,
결국 컴퓨터 시스템 또한:

- 전기 신호의 변화
- 이를 해석하는 장치
- 상태 변화를 감지하는 인터럽트와 폴링

등의 매우 낮은 수준의 동작 위에서 시작된다는 점을 이해하게 되었습니다.

이후 이러한 동작을
장치 초기화와 메모리 적재 등의 형태로 정리하는 펌웨어 계층이 존재하고,

운영체제는 다시 이를 추상화하여:
- 메모리 할당
- 프로세스 실행
- 파일 시스템

과 같은 형태의 인터페이스를 제공하게 됩니다.

그리고 대부분의 개발자는
다시 프로그래밍 언어를 통해 추상화된 메모리와 시스템 자원을 사용하게 됩니다.

결국 시스템 전체는:
상위 계층이 하위 계층의 복잡성을 감추고,
역할을 분리하며 동작하는 구조라는 점이 인상적으로 남았습니다.
