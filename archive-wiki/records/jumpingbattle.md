# JumpingBattle

Firebase 기반 다운로드 및 스트리밍 시스템 운영 프로젝트입니다.

현재 30개 이상의 매장에서 사용 중인 서비스로:

- jpg/mp3 다운로드 및 스트리밍 처리
- 기한 만료 파일 자동 삭제 시스템
- 다운로드 및 스트리밍 이벤트 기록
- Firebase 기반 상태 관리
- Zappa 기반 배포 자동화

등의 구조를 운영하였습니다.

단순 기능 구현보다,
실제 운영 환경에서의 파일 관리와 이벤트 처리 흐름,
그리고 유지보수를 고려한 구조 설계 경험을 경험할 수 있던 프로젝트입니다.
