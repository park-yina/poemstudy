검색 시스템을 구현하면서 가장 중요하게 고려한 것은 사용자가 원하는 결과를 빠르게 찾을 수 있도록 하는 것과, 실시간 갱신 환경에서도 검색 성능을 유지하는 것이었습니다.

초기 구현에서는 검색 요청이 들어올 때마다 전체 랭킹 데이터를 순회하도록 구성하였습니다. 그러나 실시간 갱신 빈도가 증가하면서 검색 비용 역시 함께 증가하는 문제가 발생하였습니다.

이후 데이터 변경 시마다 검색 인덱스를 즉시 재생성하는 대신, 변경 여부만 기록한 뒤 일정 주기로 재구성하는 Rebuild 구조를 도입하였습니다. 이를 통해 불필요한 재생성을 줄이고 검색 비용을 완화할 수 있었습니다.

또한 사용자의 기억이 항상 정확하지 않을 수 있다는 점을 고려하여, 띄어쓰기·대소문자·특수문자 등을 제거하는 정규화 과정을 검색 로직에 포함하였습니다. 이를 통해 사용자가 정확한 이름을 기억하지 못하더라도 원하는 결과를 찾을 수 있도록 구성하였습니다.
